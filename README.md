# Backyard Twin (concept)

Scroll-driven landing page for a concept product: scan a residential block with LiDAR, design a granny flat into the real yard, paint the floor plan full-size on the lawn with a line-marking robot, then hand the builder a measured site pack.

- `index.html`: the page (canvas frame scrub, chapter overlays, three.js model viewer)
- `f/1` to `f/7`: 500 AVIF frames, one folder per chapter
- `poster/`: still per chapter (reduced-motion and fallback view)
- `model/flat.js`: the 3D flat (GLB, base64-packed)

Concept visualisation. The Okafor family, their Carlingford block and all figures are examples. Imagery generated with Higgsfield (Nano Banana Pro, Kling O3, Hunyuan3D).
